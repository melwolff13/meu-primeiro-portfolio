# Meu Primeiro Portfólio

Projeto desenvolvido como parte do desafio **Meu Primeiro Portfólio**, do Programa Trilhas, com o objetivo de colocar em prática os conhecimentos adquiridos em HTML e CSS.

O portfólio apresenta meu perfil, uma breve descrição sobre mim, meus projetos e meus certificados, seguindo o [design disponibilizado no Figma](https://www.figma.com/design/py6PXkG8oYMd5v7YhKMvx4/Portfolio---Front-end?node-id=0-1&t=TqIU0HEdEF4gQ5tJ-1).

**Objetivo:** dar os primeiros passos no desenvolvimento front-end e construir um espaço para apresentar minha trajetória e evolução na área de tecnologia.
